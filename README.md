# file_renamer

Udacity Project 2

## Overview

**file_renamer** is a Python-based tool designed for efficiently renaming multiple files. This repository was created as part of Udacity's course curriculum and helps automate the tedious process of file renaming, making it especially useful for organising large numbers of files in bulk.

## Features

- Bulk renaming of files in a specified directory
- Written in Python for cross-platform compatibility
- Open source under the GNU General Public License v3.0

## Getting Started

### Prerequisites

- Python (recommended: 3.x)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Moohan/file_renamer.git
   cd file_renamer
   ```

2. (Optional) Create a virtual environment and activate it:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install dependencies (if any are listed in `requirements.txt`):
   ```bash
   pip install -r requirements.txt
   ```

### Usage

> **Note:** As this project is an educational exercise, see the main Python file (e.g., `main.py` or similar) for detailed usage examples.

A typical usage might be:
```bash
python main.py <directory_path> [options]
```
- Replace `<directory_path>` with the folder containing the files you wish to rename.
- Options may include patterns for renaming, dry-run mode, etc.
